# BlueLib Catalogue (BIT225 Assignment 2)

A single-page front-end catalogue for the BlueCrest College Library, built with HTML5, CSS3 and vanilla JavaScript only.

## Features
- Books stored in a JavaScript array and rendered dynamically as cards
- Live search by title and category filter
- Add Book form with validation (all fields required; copies must be a whole number >= 0)
- Borrow button reduces copies; shows "Out of stock" and disables at 0
- Responsive grid: 3 cards (desktop), 2 (tablet), 1 (mobile, below 600px)
- CSS variables for colours, hover effects on cards and buttons

## Structure
```
index.html
css/style.css
js/app.js
README.md
```

## Run
Open `index.html` in any modern browser.
